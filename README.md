## Короткие ответы

1. Чем отличаются `string` и `char`?

Ответ: string это строка  и пишется в двойных кавычках , а char используется только для одного символа и пишется в одинарных кавычках.

2. Почему вызов `text.Trim()` без сохранения результата не меняет `text`?

Ответ: потому что строки неизменяемые.метод не меняет исходную строку он создает новую.

3. Зачем при разделении строки используется `RemoveEmptyEntries`?

Ответ: чтобы пустые части как пробел не считались отдельнымии словами.
